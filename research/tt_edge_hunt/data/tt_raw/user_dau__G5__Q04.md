### How this was built
- Metric: Active users (daily), a unique-count metric read as each calendar day's own value (a single day is that day's reading, never averaged or summed across days).
- Cohort: the five requested projects, resolved by exact registry name — Polygon (polygon), PancakeSwap (pancakeswap), OP Mainnet (optimism), Raydium (raydium) and Ether.fi (etherfi).
- Window: 2023-03-01 through 2023-05-31, one row per calendar day; the value is read at the project level (whole project, all products combined).
- Every day in the range is present as a row; a day with no observation is left empty rather than counted as zero. Within the requested range every one of the 92 days carries a value for each of the five projects, so no "-" cells appear.
- The requested metric definitions were omitted as asked.
