### How this was built
- Metric: Active users (daily) — the number of unique addresses that made a revenue-generating transaction with the project over a fixed 24-hour window, read as each day's own value with no aggregation.
- Entities: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, resolved from the project registry by exact name.
- Window: 2024-09-01 to 2024-11-30 (91 calendar days); every day of the window is present for every project, so there are no missing days to mark.
- Values come from each project's own project-level daily active-user rows; the query returned 5 projects × 91 days = 455 rows.
