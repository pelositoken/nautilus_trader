### How this was built
- Cohort: the five named projects resolved to their registry entities — Curve, Aptos, Jupiter, Celestia and Render Network.
- Window: 2024-06-01 to 2024-08-31, one row per calendar day, no aggregation across days.
- Measure: circulating supply (number of tokens currently available for trading on the open market), read as a point-in-time token count per project per day.
- Source and grain: each project's own supply is its project-grain value; the day-by-day table is built across the full date range, and a day with no observed value is left blank rather than shown as zero.
