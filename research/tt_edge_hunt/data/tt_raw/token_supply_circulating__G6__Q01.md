### How this was built
- Metric: circulating supply (the number of tokens currently available for trading on the open market), read once per project per calendar day, one row per day across 2022-06-01 to 2022-08-31.
- Entities: Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito, each read by its canonical project id.
- Sei Network and Jito returned no observations of this metric anywhere in the window, shown as "-" on every day; Lido Finance, Cosmos Hub and Pendle returned a value for each of the 92 days.
- Cosmos Hub and Pendle each have a single constant value across the whole window; Lido Finance rises from about 393.4M on 2022-06-01 to about 591.6M on 2022-08-31.
