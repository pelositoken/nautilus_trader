### How this was built
- Active users (daily) counts the unique addresses that made a revenue-generating transaction with a project over a fixed 24-hour window; the series is read one value per project per calendar day.
- Window: the requested September 1 – November 30, 2022, shown per day; every day in the range has an observation for each project in the table, so no gap placeholders are needed.
- Values come from Token Terminal's primary project metrics at the project grain.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Filecoin's active users (daily). Token Terminal doesn't track Ondo Finance's active users (daily)._
