### How this was built
- Metric: daily active users — unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window, a unique count (each day is that day's value, not a sum).
- Cohort: the five projects resolved by exact name in the registry — Ethena, Tron, Sui, Chainlink, and Avalanche — each read whole.
- Window: 2024-09-01 through 2024-11-30, one row per calendar day; every day in the window has a value for every project, so no day is blank.
- Values come from the projects' own base metric rows, one value per project per day.
