### How this was built
- Cohort: five named projects resolved to their canonical registry entries — Polygon (polygon), PancakeSwap (pancakeswap), OP Mainnet (optimism), Raydium (raydium) and Ether.fi (etherfi); all five are public and not archived.
- Window: 2023-09-01 to 2023-11-30 (91 calendar days), returned as the window's first and last day; one row per project per day, no aggregation beyond one value per project-day.
- Value: Active users (daily) — unique addresses making a revenue-generating transaction over a fixed 24-hour window — reduced to one value per day from the project surface.
- Rows with no value on a day are returned as 0 by the query's left join; Ether.fi reads 0 across the days returned. A 0 here is the join's default for a day with no matching observation, so it cannot be read as a measured zero of usage; treat those cells as no data.
- The query returned 455 rows (91 days × 5 projects); the table shows all of them.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
