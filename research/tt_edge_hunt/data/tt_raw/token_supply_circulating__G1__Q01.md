### How this was built
- Entities: the five named projects resolved to their Token Terminal registry identities — Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap — each read at the project level.
- Metric: circulating supply, the number of tokens currently available for trading, a point-in-time token count (not summed across days).
- Window: June 1, 2022 through August 31, 2022, one row per calendar day.
- Coverage: each project had a daily value on all 92 days of the window, so every cell is an observed value and none is a gap.
- Source: each project's daily circulating-supply series on Token Terminal's project surface.
