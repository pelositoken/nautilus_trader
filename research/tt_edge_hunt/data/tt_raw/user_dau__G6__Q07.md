### How this was built
- Cohort: five named projects, each matched by exact name in the project registry — Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito.
- Measure: daily active users, the count of unique addresses making a revenue-generating transaction over a fixed 24-hour window, read at each project's own grain.
- Window: one row per calendar day from December 1, 2023 through February 29, 2024 (91 days), with every project placed in its own column and no aggregation across days or projects.
- A blank cell is a day for which the query returned no observed value for that project; it is not a zero.
- Daily active users is a unique count, so the daily readings are per-day values and are not summed.
