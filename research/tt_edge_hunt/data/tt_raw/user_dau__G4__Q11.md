### How this was built
- Window: 2024-12-01 to 2025-02-28 (the requested window, returned as its first and last day).
- Cohort: the five named projects, each resolved to its canonical project entity — Curve, Aptos, Jupiter, Celestia and Render Network — all public and live.
- Measure: active users (daily) — unique revenue-generating addresses over a fixed 24-hour window — read per project for each calendar day, with no aggregation across days.
- Each project appears as its own column and each calendar day as one row; a cell is blank (-) where the result returned no value for that project on that day.
- The returned result is 90 days × 5 projects; the requested 90 calendar days are all present.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
