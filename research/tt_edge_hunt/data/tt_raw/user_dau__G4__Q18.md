### How this was built
- Window: every calendar day from 2026-09-01 to 2026-11-15, shown at daily grain with no aggregation.
- Metric: active users (daily) — unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window — read from each project's own series.
- Cohort: the named projects Curve, Aptos and Celestia.
- Not reached: Jupiter and Render Network — a query scoped to active users (daily) for each returned no rows, so they have no column here.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Jupiter's active users (daily). Token Terminal doesn't track Render Network's active users (daily)._
