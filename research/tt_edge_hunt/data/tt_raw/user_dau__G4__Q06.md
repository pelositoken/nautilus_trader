### How this was built
- Daily active users (daily) for Curve, Aptos, Jupiter, Celestia and Render Network, one row per calendar day from 2023-09-01 to 2023-11-30, per project.
- Each project's value comes from its whole-project row for that day; every day in the window is present for all five projects, so there are no missing dates.
- Jupiter, Celestia and Render Network returned no daily active user value over this window; their columns are empty and shown as no data.
- The metric counts unique revenue-generating users over a fixed 24-hour window and was read as a per-day figure, not summed across days.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
