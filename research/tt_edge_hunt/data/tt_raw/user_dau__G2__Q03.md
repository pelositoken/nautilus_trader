### How this was built
- Cohort: Ethena, Tron, Sui, Chainlink and Avalanche, each resolved to its canonical project.
- Window: December 1, 2022 to February 28, 2023, one row per calendar day for each of the five projects.
- Value: daily active users, the unique revenue-generating addresses over a fixed 24-hour window, read per project per day.
- A cell with no value marks a day on which no daily-active-user observation was returned for that project; where no value appears, none was observed rather than a count of zero.
- Every date in the requested window appears for every project, so there are no gaps in the grid.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
