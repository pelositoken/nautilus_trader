### How this was built
- Daily active users (daily) measures the number of unique addresses making a revenue-generating transaction over a fixed 24-hour window; it is a unique count, so each calendar day is that day's own value with no aggregation across days.
- The window is 2022-07-17 through 2022-08-31 (46 calendar days), with one row per day and the five named projects as columns.
- Aave and Injective have values on every returned day; Filecoin, Ondo Finance, and Arbitrum One returned no observation on any day in this window, shown as "–".
- Values are read from each project's own daily row; no bridged or chain split applies.
