### How this was built
- Measure: active users (daily), the count of unique addresses making a revenue-generating transaction in a fixed 24-hour window, read per project per day with no aggregation over the window.
- Cohort: Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito, each resolved to its canonical project; the values are the project-level daily figures.
- Window: 2025-06-01 to 2025-08-31; every one of the 92 days is present for each of the five projects, so no day is blank and no "-" placeholder was needed.
- Source: the five projects' daily active-user rows for the window, joined to their display names; the display-name column was used only for the table header.
