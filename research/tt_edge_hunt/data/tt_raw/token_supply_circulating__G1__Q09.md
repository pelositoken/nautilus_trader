### How this was built
- Members: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, resolved by exact registry name; all five are public and unarchived.
- Window: every calendar day from 2024-06-01 to 2024-08-31 (92 days); the day list is the set of dates with observations in that range, and each entity's value is joined onto it, so a day without data shows as "-".
- Each value is the entity's circulating supply — a point-in-time count of tokens available on the open market, excluding locked, unvested and treasury-held tokens — read per day, not summed or averaged across the period.
- Every requested day returned a value for all five entities, so the table has no gaps.
