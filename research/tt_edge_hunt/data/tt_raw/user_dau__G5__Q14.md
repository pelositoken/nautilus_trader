### How this was built
- Entities: Polygon (chain-as-project), PancakeSwap, OP Mainnet (chain-as-project), Raydium and Ether.fi, each read from its own project rows.
- Metric: active users (daily) — the count of unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window; each day's figure is that day's own count, with no aggregation across days.
- Window: 2025-09-01 to 2025-11-30, one row per calendar day for each project.
- Every project was observed on all 91 days of the window, so no day is blank.
- The full daily rows (one row per project per day) are available as a CSV export on request.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
