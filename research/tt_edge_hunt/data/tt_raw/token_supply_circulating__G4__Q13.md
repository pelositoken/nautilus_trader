### How this was built
- Cohort: the five named projects — Curve, Aptos, Jupiter, Celestia and Render Network.

- Window: every calendar day from 2025-06-01 through 2025-08-31 (92 days); one value per project per day, with no aggregation.
- Each project has an observation on all 92 days, so no day required a "-" placeholder.
- Values come from the project-level metric surface, one daily snapshot per project.
