### How this was built
- Cohort: the five named projects — Ethena, Tron, Sui, Chainlink and Avalanche — each resolved to its canonical project entry; all five are currently public and live.
- Window: the 92 calendar days from March 1 to May 31, 2025, read as a day-by-day series with one row per day and no aggregation.
- Each value is the project's gross daily fees summed per project per calendar day.
- The grid is built as every calendar day crossed with every project and left-joined to the observed daily fees, so a day on which a project has no returned fee observation appears as 0 in the grid rather than a blank.
- Fees measure gross value users pay to use a project's application; a value of 0 is a returned cell, not an absence of coverage.
