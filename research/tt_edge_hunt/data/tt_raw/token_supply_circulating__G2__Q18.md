### How this was built
- The table is daily circulating supply (token count) for the five named entities — Ethena, Tron, Sui, Chainlink and Avalanche — one row per calendar day, projects as columns. Each is read at its own project grain (the chains read as their own chain rows).
- Window: every day from 2026-09-01 through 2026-11-15 (76 calendar days), one row per day.
- Circulating supply is a point-in-time balance (the number of tokens available for trading, excluding locked, unvested, and treasury-held tokens), so each day's cell is that day's reading, not a sum or average.
- Every one of the 76 days had a value for all five entities, so no day required a "-" placeholder.
- Latest observation for all five entities: 2026-11-15.
