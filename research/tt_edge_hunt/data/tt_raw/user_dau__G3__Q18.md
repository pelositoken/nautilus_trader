### How this was built
- Cohort: the projects the question names. Filecoin and Ondo Finance are not tracked for active users (daily), so they are absent here.
- Window: 2026-09-01 to 2026-11-15, one row per calendar day; each project covers all 76 days with no gaps (the window's last day is 2026-11-15).
- Source: active users (daily) read for each project from its own project rows, one value per day; each cell is that single day's count.
- Active users (daily) counts unique addresses making a revenue-generating transaction over a fixed 24-hour window, so each day stands alone and the days are not summed.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Filecoin's active users (daily). Token Terminal doesn't track Ondo Finance's active users (daily)._
