### How this was built
- Cohort: the five entities named in the question, each resolved by exact registry name — Ethereum, Solana, BNB Chain, NEAR Protocol, and Uniswap.
- Metric: circulating supply, the number of tokens available for trading on the open market, read as each day's own value (a point-in-time count, not summed across days).
- Window: one row per calendar day from 2024-03-01 through 2024-05-31 (92 days), with each entity's daily value placed in its own column; every day in the window returned a value for all five projects, so no cell is blank.
