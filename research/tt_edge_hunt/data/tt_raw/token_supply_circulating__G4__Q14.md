### How this was built
- Cohort: the five named projects — Curve, Aptos, Jupiter, Celestia and Render Network — each read from its own project record.
- Metric: circulating supply, the number of tokens available for trading (a point-in-time token count, unitless), read as each project's daily value.
- Window: 2025-09-01 through 2025-11-30 (91 calendar days). Every one of those days returned an observation for each of the five projects, so no day is written as "-".
- Values are the raw token counts; the table shows every day of the window, one row per date and one column per project.
