### How this was built
- Cohort: the five named projects resolved to their canonical registry entries — Aave, Arbitrum One, Filecoin, Injective and Ondo Finance.
- Metric: daily active users, the number of unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window.
- Window: 2023-09-01 to 2023-11-30 (91 calendar days), read per calendar day with no aggregation.
- Values come from each project's own daily active-user rows; each day is that day's reading.
- Filecoin and Ondo Finance returned no daily active-user observations in the returned window, so their days are shown with no value ("-").
- Not reached: nothing — every requested project and day is covered by the returned rows.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
