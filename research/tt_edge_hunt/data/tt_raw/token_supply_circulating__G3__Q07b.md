### How this was built
- The five named projects were resolved by exact name to their canonical entities: Aave, Injective, Filecoin, Ondo Finance and Arbitrum One.
- Circulating supply is a point-in-time token count — tokens available for trading, excluding locked, unvested, and treasury-held tokens — read from the project surface. Each row is that single day's count; the values are not summed over days.
- Window: January 16, 2024 through February 29, 2024 (45 calendar days), one row per day for every day in the window.
- Aave, Injective, Filecoin and Arbitrum One carry a value on all 45 days; Ondo Finance carries a value on 42 of 45 days — no observed value on January 16–18, 2024, shown blank.
