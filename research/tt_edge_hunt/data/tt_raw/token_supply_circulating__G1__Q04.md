### How this was built
- Entities: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, each resolved to its live registry entry by exact name.
- Measure: circulating supply — a point-in-time token count (tokens available for trading on the open market), not a flow; each day's value is that day's latest observation.
- Window: 2023-03-01 through 2023-05-31, 92 calendar days, one row per day per project (460 rows).
- Every one of the 92 days has a value for all five projects, so no day needed a "-" placeholder.
- No aggregate, average or total is shown; values are the raw daily counts.
