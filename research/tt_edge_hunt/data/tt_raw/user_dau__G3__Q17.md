### How this was built
- Active users (daily) measures the unique addresses that make a revenue-generating transaction with a project over a fixed 24-hour window; each cell is that project's value for that calendar day, with no aggregation across days.
- The window is June 1 to August 31, 2026, read as one row per calendar day.
- Aave, Injective and Arbitrum One each have a value on all 92 calendar days in the window; no day is missing a value, so no gap markers appear.
- Not reached: no active users (daily) rows were returned for Filecoin or Ondo Finance, so neither appears as a column.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Filecoin's active users (daily). Token Terminal doesn't track Ondo Finance's active users (daily)._
