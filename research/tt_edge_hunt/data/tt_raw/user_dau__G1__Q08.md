### How this was built
- Measure: daily active users — unique addresses that make a revenue-generating transaction with the project, over a fixed 24-hour window. Figure for each project on each day.
- Entities: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, matched by exact registry name.
- Window: 2024-03-01 to 2024-05-31, one row per calendar day per project (92 days × 5 projects).
- Each value comes from the project-level daily reading of the metric for that project and day; no aggregation across days or projects was applied.
