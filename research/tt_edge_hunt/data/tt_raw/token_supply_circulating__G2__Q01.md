### How this was built
- Cohort: the five projects named in the question, resolved to their canonical project identities (Ethena, Tron, Sui, Chainlink, Avalanche), all public and not archived.
- Window: June 1, 2022 through August 31, 2022, one row per calendar day (92 days), with each day included even when no value was observed.
- Measure: circulating supply (a point-in-time token count, number of tokens available for trading on the open market), read as the latest observed value per project per day; rows are one per day and project, and the series is shown unaggregated.
- Where each value comes from: circulating supply on the project surface, one observation per project per day.
- Ethena and Sui have no observation in this window, so their column shows a dash on every day; every day is still present, so the series has no missing calendar rows.
