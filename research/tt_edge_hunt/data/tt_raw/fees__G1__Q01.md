### How this was built
- Fees for Ethereum, Solana, BNB Chain and NEAR Protocol are read from each chain's own project rows (its own activity), and Uniswap from its project row.
- Fees is a flow measure, so each row is that single calendar day's gross user-paid fees in USD — one row per day, no summing across days.
- Window: 2022-06-01 to 2022-08-31. The query returned 92 daily rows for each of the five entities (460 rows in total), covering every calendar day of the window with no missing days.
- Values are gross fees users pay, not revenue.
