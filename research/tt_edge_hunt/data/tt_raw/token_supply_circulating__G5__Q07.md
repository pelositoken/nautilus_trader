### How this was built
- Cohort: Polygon, PancakeSwap, OP Mainnet, Raydium and Ether.fi, each resolved to its registry identity and all currently listed.
- Window: 2023-12-01 to 2024-02-29, read as 91 calendar days; a row is generated for every day and left-joined to the data, so a day with no observation shows "-".
- Each day's value is that project's closing circulating supply — the number of tokens available for trading, a point-in-time token count; nothing is summed or averaged across days.
- Ether.fi has no observed supply in this window; its series begins 2024-03-18, after the window end.
- Polygon's series begins 2023-10-26, PancakeSwap's 2020-10-20, OP Mainnet's 2022-06-01 and Raydium's 2021-02-22, so all four cover the full window.
