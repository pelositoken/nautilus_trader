### How this was built
- Metric: circulating supply, the number of tokens currently available for trading on the open market (excludes tokens that are locked, unvested, or held in the project's own treasury); a point-in-time token count, not summed across days.
- Window: 2023-12-01 through 2024-02-29 (91 calendar days), one row per day, no aggregation.
- Entities: Ethena, Tron, Sui, Chainlink and Avalanche, read at the project grain exactly as resolved — Ethena, Chainlink (projects) and Tron, Sui, Avalanche (chains read on their own project rows).
- Coverage: Tron, Sui, Chainlink and Avalanche each have an observation on all 91 days of the window; the daily values are the token counts as stored for each day.
- Ethena: no circulating-supply observation in this window — its first observation is 2024-04-02 — so its column shows no data for every day here. This is a gap in the requested slice, not a zero.
- The full day-by-day rows are the rendered table above; a CSV export is available on request.
