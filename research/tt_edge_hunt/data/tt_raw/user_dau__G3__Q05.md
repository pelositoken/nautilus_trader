### How this was built
- Entities: Aave (project), Injective (project), and Arbitrum One (read as its own chain project). Filecoin and Ondo Finance are not reached — Token Terminal does not track active users (daily) for them, so they have no column.
- Metric: active users (daily), the number of unique addresses making a revenue-generating transaction over a fixed 24-hour window; each cell is that calendar day's own reading, not an aggregate.
- Window: 2023-06-01 to 2023-08-31 (92 calendar days), one row per day.
- Coverage: each of the three tracked entities has an observation on every one of the 92 days, so no day needed a gap marker.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Filecoin's active users (daily). Token Terminal doesn't track Ondo Finance's active users (daily)._
