### How this was built
- Cohort: the five named projects, resolved in the registry as Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap; fees are read from each project's own whole-project row.
- Window: daily fees for 2025-06-01 through 2025-08-31 (92 calendar days), one row per day with each project as its own column; no period aggregation was applied.
- Measure: fees, the total value users pay to use the protocol (gross, user-paid fees), summed per project per calendar day and shown in USD.
- A day spine of all 92 dates is left-joined to each project's daily values, so any day a project has no data for renders blank rather than being dropped.
