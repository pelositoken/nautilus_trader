### How this was built
- Cohort: the five projects named in the question, each resolved by exact registry name to Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap.
- Window: 2023-09-01 to 2023-11-30, returned as requested_window_start and requested_window_end.
- Measure: daily active users — unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window — read at one row per project per calendar day from the project-level metrics surface. No aggregation across days.
- Grain: one row per date and project; the grid returns a row for every one of the 91 calendar days for each of the five projects (455 rows in total).
- A date with no observed value renders as "–".
- Not reached: nothing; every requested day and project was returned.
