### How this was built
- Fees are gross amounts users pay to use each project; each cell is that project's fee value for that calendar day, with no aggregation over time (the daily value as returned). Window: 2023-03-01 to 2023-05-31.
- Projects are read at the project surface for Curve, Aptos, Jupiter and Celestia.
- Values are USD.
- Not reached: the gap-filled single wide table with a dash for days where a project has no data. No query returned it, so the table shows only the days on which an observation exists; a day with no data for a project appears blank rather than as "-".
