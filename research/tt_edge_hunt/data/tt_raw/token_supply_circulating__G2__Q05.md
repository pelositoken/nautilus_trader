### How this was built
- Entities: Ethena, Tron, Sui, Chainlink and Avalanche, each resolved to its public project in the project registry (all five are public, non-archived).
- Metric: circulating supply, a point-in-time token count (tokens available for trading on the open market, excluding locked, unvested and treasury-held tokens). Each calendar day shows that day's observed value; values are not summed or otherwise aggregated across days.
- Window: 2023-06-01 to 2023-08-31, one row per calendar day — 92 days, every one of which is present in the result for all five projects.
- Days with no observed value for a project are returned with no value rather than a number; in this window that is every day for Ethena, which returned no circulating-supply observation from 2023-06-01 through 2023-08-31.
- Values come from the project-level metrics surface at project grain, one row per project per day.
