### How this was built
- Cohort: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, resolved by exact registry name; all five are public and live.
- Measure: Active users (daily) — unique addresses making a revenue-generating transaction with the project, over a fixed 24-hour window; each value is that day's figure.
- Window: June 1, 2024 through August 31, 2024 (92 calendar days), returned as the requested window on every row.
- Every calendar day in the window has an observation for every one of the five projects, so no "-" placeholders appear in the table.
