### How this was built
- Daily circulating supply, one row per calendar day per project, for the window July 17 – August 31, 2022 (46 days), for the five named projects.
- Circulating supply is the point-in-time count of tokens available for trading on the open market, read as that day's value (not summed across days).
- PancakeSwap, OP Mainnet and Raydium returned a value on every day of the window.
- Polygon and Ether.fi returned no value on any day of this window, so those cells are blank — no data was observed for them, not a zero.
- Not reached: no values for Polygon or Ether.fi, as neither returned any row in this window.
