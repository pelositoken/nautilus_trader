### How this was built
- Cohort: the five projects named — Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito.
- Metric: each project's circulating token supply, a point-in-time token count (not a USD value).
- Window: 2025-03-01 through 2025-05-31, one row per calendar day per project (92 days × 5 projects = 460 rows).
- Each cell is that project's own daily circulating-supply observation for the day; every project had an observation on all 92 days, so no cell is a gap.
- Values are read from the project-level surface at project grain; a point-in-time token count is never summed across days, so each day shows that day's standing supply.
