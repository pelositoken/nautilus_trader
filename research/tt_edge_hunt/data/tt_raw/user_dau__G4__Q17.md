### How this was built
- Metric: active users (daily) — unique addresses making a revenue-generating transaction over a fixed 24-hour window, read once per calendar day.
- Entities: Curve (project), Aptos (chain), Celestia (chain), each read from its own daily rows.
- Window: 2026-06-01 to 2026-08-31; all three covered entities have a value on every one of the 92 days, so no day is blank.
- Not reached: daily active users for Jupiter and Render Network, which this metric has no rows for.
- The per-day rows are what the grid renders; a finer or longer daily export is available as a CSV on request.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Jupiter's active users (daily). Token Terminal doesn't track Render Network's active users (daily)._
