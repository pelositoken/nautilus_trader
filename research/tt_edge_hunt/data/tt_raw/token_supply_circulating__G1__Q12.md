### How this was built
- Cohort: the four chains Ethereum, Solana, BNB Chain and NEAR Protocol read as their own native-token supply, plus the Uniswap project read as its governance token UNI.
- Measure: circulating supply — the number of tokens currently available for trading on the open market, excluding locked, unvested, or treasury-held tokens. It is a point-in-time balance, so each day shows that day's value and nothing is summed across days.
- Source: project-level daily metrics for these names.
- Window: requested 2025-03-01 through 2025-05-31; the data covers all 92 days, as of 2025-05-31.
- Coverage: every one of the 92 days has a value for all five entities (460 entity-days total), so no date is blank and no placeholder is needed.
