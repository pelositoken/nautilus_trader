### How this was built
- Metric: Active users (daily) — the count of unique revenue-generating users over a fixed 24-hour window. Each row is a single day's reading; no window aggregation was applied.
- Window: every calendar day from December 1, 2025 to February 28, 2026 (90 days), with one row per day so the series has no gaps.
- Cohort: the five named projects — Aave, Arbitrum One, Filecoin, Injective and Ondo Finance — matched to their canonical registry identities.
- Values are the daily active-user observations for each project on each date.
- Filecoin and Ondo Finance returned no active-user observations for any day in the window, so their columns carry no figures (unavailable / not observed, not zero).
