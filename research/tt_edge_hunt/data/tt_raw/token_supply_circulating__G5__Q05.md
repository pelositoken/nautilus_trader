### How this was built
- Circulating supply (token count) is a point-in-time balance per project per day; the window is 2023-06-01 to 2023-08-31, one row per calendar day, shown as a day × project grid.
- The grid is built explicitly for all five projects against every calendar day in the window, so a day with no observation shows "–" rather than being dropped.
- Projects are Polygon, PancakeSwap, OP Mainnet, Raydium and Ether.fi, each resolved to its canonical project registry entry.
- Polygon and Ether.fi returned no circulating-supply values in this window; their cells are blank for every day.
