### How this was built
- Daily active users (daily) for Curve, Aptos and Celestia, one row per calendar day from 2025-09-01 through 2025-11-30; each cell is that day's own reading, with no aggregation across days.
- The metric counts unique addresses that make a revenue-generating transaction with the project over a fixed 24-hour window, so it is narrower than all-address activity.
- Each of the three projects has a reading on every day of the window (91 days apiece), so no day in the range is missing and no dash is needed for them.
- Curve, Aptos and Celestia each carry data through the last day of the requested window.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Jupiter's active users (daily). Token Terminal doesn't track Render Network's active users (daily)._
