### How this was built
- The five named projects were resolved to their canonical entities: Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito.
- The measure is circulating supply — the token count available for trading on the open market — read from each project's own project-level record, one observation per calendar day, unaggregated. It is a point-in-time balance, not summed across days.
- The window is 2023-07-17 through 2023-08-31 (46 calendar days); every day is returned, and a project with no observation on a day is shown as a dash rather than zero.
- Coverage in this window is not uniform: Lido Finance, Cosmos Hub and Pendle have a value on every day; Sei Network first has an observed value on 2023-08-15 (dashes before that); Jito has no observed value on any day in the window and is dashes throughout.
