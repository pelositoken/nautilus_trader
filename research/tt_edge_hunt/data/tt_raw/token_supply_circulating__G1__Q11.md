### How this was built
- The window is December 1, 2024 to February 28, 2025 (requested_window_start 2024-12-01, requested_window_end 2025-02-28).
- Entities: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, resolved from the project registry by exact name.
- Circulating supply is a point-in-time token count (tokens currently available for trading, excluding locked, unvested or treasury-held tokens); each day's value is that day's observation, read with the metric's last-value reducer and not summed across days.
- Every one of the 90 days has a value for all five projects, so no day required a "-" placeholder.
