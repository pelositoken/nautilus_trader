### How this was built
- Metric: circulating supply — the number of each project's tokens available for trading on the open market, read as a balance (point-in-time token count) for each project.
- Entities: Ethena, Tron, Sui, Chainlink and Avalanche, resolved to their canonical project rows.
- Window: one row per calendar day from March 1, 2025 through May 31, 2025 (92 days); every day in the window is present as its own row, and a day on which a project has no observation is left without a value.
- Values come from the project-level metrics surface at one row per project per day.
- Metric definitions were skipped as requested.
