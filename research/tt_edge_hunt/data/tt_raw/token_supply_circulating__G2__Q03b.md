### How this was built
- Cohort: the five named projects — Ethena, Tron, Sui, Chainlink and Avalanche — each read on the project surface.
- Window: every calendar day from 2023-01-15 through 2023-02-28, one row per day, no aggregation across days.
- Measure: circulating supply, the number of tokens available for trading on the open market, read as the point-in-time balance for each day; it is not summed across the period.
- Days with no returned observation carry no value in the table; Ethena and Sui returned no circulating-supply observation on any day of the window.
