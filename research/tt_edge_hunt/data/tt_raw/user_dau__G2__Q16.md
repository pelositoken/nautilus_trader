### How this was built
- Daily active users is the unique count of addresses making a revenue-generating transaction over a fixed 24-hour window; each project × day is read directly with no aggregation across days.
- Cohort: Ethena, Tron, Sui, Chainlink and Avalanche, matched by exact project name among public, non-archived projects (all five resolved).
- Window: 2026-03-01 to 2026-05-31 (the returned window columns); all 92 calendar days are present, one row per day, no gaps.
- Cells with no observed value are left blank (unavailable), which is distinct from a returned 0, a measured zero-activity day — for example Ethena has no value on 2026-03-01.
