### How this was built
- Cohort: the five projects named in the question, each read as its own project-level row — Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito.
- Metric: circulating supply, the number of the project's tokens currently available for trading, read as a point-in-time balance (each day's own value, no aggregation across days).
