### How this was built
- Cohort: the five named projects, each resolved by exact registry name — Polygon, PancakeSwap, OP Mainnet, Raydium and Ether.fi (all public and not archived).
- Metric: circulating supply — the point-in-time count of tokens available for trading on the open market, excluding locked, unvested or treasury-held tokens. It is a balance, so each calendar day carries that day's reading and nothing is summed across days.
- Window: 2025-06-01 to 2025-08-31 (the requested window), one row per calendar day per project.
- Values come from the projects' own base project metrics at project grain.
- Coverage: all 92 calendar days returned a value for every one of the five projects, so no day is blank and no "-" appears.
