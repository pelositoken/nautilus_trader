### How this was built
- The window is the requested calendar range, 2023-03-01 through 2023-05-31, one row per calendar day; each day carries its own value with no aggregation, and a day with no observed value is shown as "-".
- The measure is Active users (daily) — unique revenue-generating users over a fixed 24-hour window — read at project grain.
- The projects queried: Curve, Aptos, Jupiter, Celestia and Render Network.
- Curve and Aptos returned a value for the days in the window; Jupiter, Celestia and Render Network returned no value for this window, so their columns stay empty.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
