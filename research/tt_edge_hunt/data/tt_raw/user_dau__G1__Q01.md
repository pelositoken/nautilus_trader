### How this was built
- Entities resolved by exact registry name: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap (all public and unarchived).
- Metric read: Active users (daily) — unique addresses making a revenue-generating interaction with the project, over a fixed 24-hour window. Each day is that day's own value; no amount, average or other aggregation was applied across days or entities.
- Window: every calendar day from 2022-06-01 through 2022-08-31 (92 days). A full calendar spine was generated so the table has one row per day per entity — 460 rows in total — and a day an entity has no observation for renders as "-" rather than being dropped.
- Values come from the project-level metrics surface; the metric is a distinct count, so the five columns are not additive and are shown side by side, not summed.
