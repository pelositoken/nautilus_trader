### How this was built
- Entities: Curve, Aptos, Jupiter, Celestia and Render Network, each resolved to its public project in the registry.
- Metric: Active users (daily), the count of unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window, read per calendar day with no aggregation across days.
- Window: 2025-06-01 to 2025-08-31, inclusive (92 calendar days, one row per day); a day with no observation is shown as "-".
- Not reached: Jupiter and Render Network returned no daily active user observations for any day in this window; their columns are "-" throughout.
- Counts are not additive across days or entities (unique counts).
