### How this was built
- Cohort: the five named projects resolved by exact name in the project registry — Polygon, PancakeSwap, OP Mainnet, Raydium and Ether.fi — each a live public project.
- Window: 2024-03-01 through 2024-05-31, one row per calendar day (92 days), each project read on each day.
- Metric: circulating supply — the number of tokens currently available for trading on the open market, excluding locked, unvested and treasury-held tokens; a point-in-time balance, so each day shows that day's value and the values are not summed across days.
- Source and grain: the project-level project metrics surface, one value per project per day, reduced to the day's value where a day carried more than one reading.
- Days with no observation are shown as "-": Ether.fi has no circulating-supply value for 2024-03-01 through 2024-03-17 (its first value in the window is 2024-03-18, 115,200,000); every other project has a value on every day of the window.
- The full window spans 460 rows (92 days × 5 projects), all returned and shown.
