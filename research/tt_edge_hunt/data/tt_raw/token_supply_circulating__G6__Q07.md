### How this was built
- Cohort: the five projects named in the question, resolved to Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito; all five are public.
- Window: 2023-12-01 to 2024-02-29, one row per calendar day, no aggregation, with each project as a column; a day a project has no value is shown as "-".
- Measure: circulating supply, the number of tokens currently available for trading on the open market, read as the day's value (a point-in-time token count, not summed across days); values are unitless token counts.
- Source: the projects' own circulating-supply rows over the window.
- Coverage: Sei Network, Lido Finance, Cosmos Hub and Pendle have a value on every day of the window; Jito has no value for December 1–6, 2023, and its first value in the window falls on December 7, 2023 (115,000,000).
