### How this was built
- The five projects were resolved by exact registry match: Ethena, Tron, Sui, Chainlink and Avalanche.
- The measure is active users (daily), the count of unique addresses making a revenue-generating transaction with each project over a fixed 24-hour window; each row is that calendar day's own value.
- Window: 2025-03-01 to 2025-05-31, 92 calendar days.
- Values come from each project's base project metrics at daily grain.
- Every one of the 92 days returned a value for each of the five projects, so no cell is a gap; Ethena's zeros on some days are measured values of zero, not missing data.
