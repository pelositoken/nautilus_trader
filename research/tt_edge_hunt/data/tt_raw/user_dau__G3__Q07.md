### How this was built
- Metric: Active users (daily) — unique revenue-generating users over a fixed 24-hour window — read at one row per project per calendar day.
- Cohort: the five named projects, resolved in the project registry to Aave, Injective, Filecoin, Ondo Finance and Arbitrum One.
- Window: requested December 1, 2023 through February 29, 2024; every day of the window is returned, so there are no missing dates.
- Filecoin and Ondo Finance have no observed daily-active-user value on any day in this window, so their columns are empty throughout. This means no value was observed for them here; the other three projects have values.
- Values are as of each returned calendar day; no aggregation was applied across days.
