### How this was built
- Cohort: the five entities the question names — Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap — each read on its own project surface, so each column is that project's or chain's own token circulating supply.
- Window: 2023-09-01 through 2023-11-30, one row per calendar day, 91 days, no aggregation.
- Each value is the day's circulating supply, a point-in-time token count (tokens available for trading on the open market, excluding locked, unvested or treasury-held tokens), read from each entity's own daily row.
- Coverage: all five entities have a value on all 91 days (first day 2023-09-01, last day 2023-11-30), so the table is complete and no day requires a "no data" marker.
- These are the full-grain daily rows; a CSV export is available if you want them as a file.
