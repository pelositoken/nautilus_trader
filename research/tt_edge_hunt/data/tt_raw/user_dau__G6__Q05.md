### How this was built
- Measure: Active users (daily), unique revenue-generating users over a fixed 24-hour window, read per project per day.
- Window: 2023-06-01 to 2023-08-31, one row per calendar day, every day of the range carried.
- Entities: Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito, each resolved to its Token Terminal project.
- A day a project has no observed value is shown as "-" rather than zero.
- Sei Network: no value was observed on any day of this window; its row is the project's listing date, 2024-01-19, which falls after the window.
- Every project except Sei Network has a value on each day of the window.
