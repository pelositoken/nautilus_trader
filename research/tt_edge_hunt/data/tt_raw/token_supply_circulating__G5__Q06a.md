### How this was built
- Cohort: the five projects named in the question, resolved to their registry entries — Polygon, PancakeSwap, OP Mainnet, Raydium and Ether.fi.
- Metric: circulating supply, the number of tokens currently available for trading on the open market, read as each project's stored value for each calendar day at project grain, with no aggregation across days and no summing across periods.
- Window: 2023-09-01 to 2023-10-15, as requested; the observed days run 2023-09-01 to 2023-10-15.
- Coverage: Polygon and Ether.fi have no observation of circulating supply anywhere in this window, so their columns are empty throughout. The earliest tracked observation of this metric is 2023-10-26 for Polygon and 2024-03-18 for Ether.fi, both after the requested window; this is a coverage gap for the scoped window only, not a claim that the projects or their tokens do not exist.
- Cells left blank are days on which no value was observed; they are not zeros and are not treated as zero supply.
- Values are unrounded token counts as served.
- Not reached: nothing — every requested part was covered, with the Polygon and Ether.fi columns reported as empty for the window.
