### How this was built
- Cohort: the five projects you named, each resolved by exact registry name — Sei Network, Lido Finance, Cosmos Hub, Pendle, Jito.
- Metric: each project's circulating supply, a point-in-time token count reported at the project level. Each day's figure is that day's snapshot and is never summed across days.
- Window: 2024-09-01 through 2024-11-30 (the first and last days returned), giving one row per calendar day for each of the five projects.
- Gaps: every calendar day is present as a row; a day on which a project has no circulating-supply observation shows as "-".
- The token count is treated as unitless.
