### How this was built
- Window: every calendar day from 2025-09-01 through 2025-11-30 (91 days), one row per day, no aggregation across days.
- Metric: active users (daily) — the number of unique addresses that made a revenue-generating transaction with the entity over a fixed 24-hour window.
- Entities: Aave, Injective and Arbitrum One, each read as its own row for each day; all three have a value on every day of the window, so no day is blank.
- Not reached: Filecoin and Ondo Finance, which Token Terminal does not track on this metric.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Filecoin's active users (daily). Token Terminal doesn't track Ondo Finance's active users (daily)._
