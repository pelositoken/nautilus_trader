### How this was built
- Cohort: the five named entities resolved by exact registry name — Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap (each a live public project).
- Window: the calendar days 2023-03-01 through 2023-05-31, one row per day per entity, no aggregation; a day with no observed value renders as a dash.
- Metric: Active users (daily) — the number of unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window; read from each project's own project-level daily row, reduced to one value per day per entity.
- Each daily cell carries an observation marker so a missing day is distinguishable from a measured zero.
