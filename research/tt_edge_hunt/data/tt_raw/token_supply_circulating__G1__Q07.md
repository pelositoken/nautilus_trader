### How this was built
- Cohort: the five named entities resolved in the project registry — Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap — each read at its own project grain.
- Metric: circulating supply, the number of tokens currently available for trading, read as a point-in-time balance per day from the project metrics surface (one value per project per calendar day).
- Window: 2023-12-01 through 2024-02-29 (91 calendar days), one row per day per entity, exactly as requested, with no aggregation across days.
- Coverage: every one of the five entities has an observation on all 91 days of the window (first observed day 2023-12-01, last observed day 2024-02-29), so no day in the window lacked data and no gap placeholder was needed.
- Metric definitions were omitted at your request.
