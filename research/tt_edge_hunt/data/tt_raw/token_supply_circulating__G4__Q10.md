### How this was built
- Cohort: the five named projects — Curve, Aptos, Jupiter, Celestia and Render Network — resolved to their canonical registry entries.
- Measure: circulating supply (a token count, unitless) — the number of tokens currently available for trading on the open market, read as a point-in-time stock on each calendar day.
- Window: every calendar day from 2024-09-01 through 2024-11-30 (91 days).
- Coverage: all 91 days carry an observation for each of the five projects, so the table has no missing cells (no day required a blank).
- Source and grain: project-level daily values; no aggregation was applied across days.
