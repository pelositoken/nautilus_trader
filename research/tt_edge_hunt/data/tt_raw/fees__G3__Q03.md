### How this was built
- Cohort: the five named projects, resolved in the project registry — Aave (`aave`), Injective (`injective`), Filecoin (`filecoin`), Arbitrum One (`arbitrum`) and Ondo Finance (`ondo`).
- Window: 2022-12-01 to 2023-02-28, the full calendar range requested, one row per day per project (90 days × 5 projects = 450 rows).
- Metric: gross daily fees (the value users pay to use each project), summed per project per calendar day from the project-level metrics table; daily figures are not aggregated across the window.
- Values come from each project's project-level fee rows; a dash is a day with no fee observation for that project. Ondo Finance carries no fee observation on any day of this window (its Token Terminal listing date is 2024-03-14, after the range).
- Aave, Arbitrum One, Filecoin and Injective each have a fee observation on every day of the window.
