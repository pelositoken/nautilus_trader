### How this was built
- Daily circulating supply (token count) for Ethena, Tron, Sui, Chainlink and Avalanche, one row per calendar day, each project as a column.
- Window: December 1, 2025 to February 28, 2026 (90 days).
- Each cell is that day's point-in-time circulating-supply count for the project; supply is a balance and is read as the day's observed value, not an average over the window.
- Every one of the five projects has a value on every day of the window (450 day-project points across 90 days), so no day is missing and no "-" placeholder is needed.
