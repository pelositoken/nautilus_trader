### How this was built
- Metric: daily active users — unique addresses that made a revenue-generating transaction with the project, over a fixed 24-hour window; read at each entity's project level.
- Window: 2026-03-01 to 2026-05-31, one row per calendar day, no weekly/monthly bucketing and no window aggregation; each day's figure is that single day's value.
- Entities: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, resolved by exact name in the project registry.
- The table is pivoted from a long result (one row per project per day) into one column per project.
