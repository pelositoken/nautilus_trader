### How this was built
- Window: every calendar day from 2022-12-01 to 2023-02-28 (the requested window start and end returned by the query), one row per day, one column per project.
- Cohort: the five named projects, resolved to Aave, Injective, Filecoin, Ondo Finance and Arbitrum One.
- Measure: circulating supply (tokens available for trading on the open market), a point-in-time balance that is not summed across periods; each day is that day's value.
- Source: project-level base metrics at one row per project per day.
- Coverage: Aave, Filecoin and Injective each observed on 90 days (2022-12-01 through 2023-02-28). Ondo Finance and Arbitrum One returned no circulating-supply rows for any day in the window, so their cells are blank rather than zero.
- Not reached: circulating supply for Ondo Finance and Arbitrum One over this window — no query returned a value for them.
