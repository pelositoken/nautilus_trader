### How this was built
- **Cohort:** the five named entities — Sei Network (`seinetwork`), Lido Finance (`lido`), Cosmos Hub (`cosmos`), Pendle (`pendle`) and Jito (`jito`); each is read from its own project row.
- **Metric:** circulating supply — a point-in-time token count (a balance, not a flow), one value per project per calendar day.
- **Window:** 2024-12-01 to 2025-02-28, one row per day, unaggregated.
- **Coverage:** each project has a value on all 90 days of the window, so no day is missing and no dash appears.
