### How this was built
- Daily circulating supply (token count) for Ethena, Tron, Sui, Chainlink and Avalanche, for each calendar day from 2024-12-01 through 2025-02-28.
- Each cell is that day's point-in-time circulating supply (tokens available for trading on the open market), not a value summed across days.

- Values are Token Terminal's circulating-supply metric read at the project grain for each of the five named entities.
