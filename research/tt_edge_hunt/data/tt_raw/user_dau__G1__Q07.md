### How this was built
- Metric: daily active users, a unique count measured over a fixed 24-hour window, taken as each project's own daily reading (one value per project per calendar day, no aggregation across days).
- Cohort: the five projects named in the question, resolved by exact registry name — Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap.
- Window: December 1, 2023 to February 29, 2024, the dates the question named; the table's grid covers one row per calendar day across that window.
- A project-day with no observation is left blank in the grid; every project-day carried a single daily reading.
- Values are counts of unique users and are unitless.
