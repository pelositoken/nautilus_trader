### How this was built
- Daily revenue in USD for Aave, Injective, Filecoin, Ondo Finance and Arbitrum One, one row per calendar day, no aggregation across days; the window is 2024-09-01 to 2024-11-30 (91 days).
- Revenue is the fee revenue a project retains after supply-side payouts; each day's value is that day's revenue for the project.
- A "-" in a cell marks a day with no observation for that project. For Injective a $0 is a measured value (the project retained no revenue that day), which is different from a missing day.
- Ondo Finance returned no revenue observation on any day in this window; every day is shown as "-".
