### How this was built
- Cohort: the five named projects resolved by exact registry name — Sei Network, Lido Finance, Cosmos Hub, Pendle and Jito.
- Window: the 90 calendar days from 2022-12-01 through 2023-02-28, one row per day, taken as each project's circulating supply on that day.
- Source: circulating supply (the number of tokens available for trading on the open market, excluding locked, unvested, and treasury-held tokens), read as a point-in-time token count per project per day.
- Days with no observed value are shown as `-`: Lido Finance, Cosmos Hub and Pendle have values across the window; Sei Network and Jito have no observed circulating-supply value on any day in this window and appear as `-` throughout.
- The table renders all 450 returned rows (90 days × 5 projects); the values are unrounded token counts.
