### How this was built
- The requested set was Aave, Injective, Filecoin, Ondo Finance and Arbitrum One; the metric is active users (daily), a count of unique revenue-generating users over a fixed 24-hour window.
- The window is 2022-06-01 through 2022-07-16 (46 calendar days), read at one row per member per calendar day at the project grain, with no aggregation across days.
- Values shown are for Aave and Injective, the only two of the requested members with observations in this window; each is present on all 46 days, so the series has no gaps for them.
- Not reached: Ondo Finance, whose active users (daily) is not tracked. Not reached: Filecoin and Arbitrum One, which returned no active users (daily) observations in this window.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Ondo Finance's active users (daily)._
