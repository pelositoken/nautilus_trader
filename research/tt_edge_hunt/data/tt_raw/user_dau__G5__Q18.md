### How this was built
- **Daily active users**, which measures the number of unique addresses making a revenue-generating transaction with a project over a fixed 24-hour window, shown per calendar day.
- Window: 2026-09-01 to 2026-11-15, one row per day.
- Entities: Polygon, PancakeSwap, OP Mainnet, Raydium and Ether.fi, each read from its own project row.
- Every day in the requested range is present; a day with no observation is shown as "-".

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
