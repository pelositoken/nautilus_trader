### How this was built
- Daily active users is Token Terminal's active-users (daily) measure: unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window. It is a count of distinct users, so a day's figure is that day's value and no aggregation over days was applied.
- Window: 2023-09-01 to 2023-11-30, one row per calendar day per project, all five projects as columns.
- Values are read from each project's own daily rows; each project is a single entity column, not a sum.
- Ethena has no observations between 2023-09-01 and 2023-11-19; its first observation in the window is 2023-11-20, so those earlier days are shown as "-".
- Avalanche, Chainlink, Sui and Tron each have observations for every day of the window.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
