### How this was built
- Cohort: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, resolved by exact name in the project registry (all live and unarchived).
- Metric: circulating supply — the number of tokens currently available for trading, taken as a point-in-time token count (a snapshot), not summed across days.
- Window: 2025-06-01 through 2025-08-31, read one value per calendar day per project with no period aggregation.
- Each day in the window has a value for all five projects, so no day is blank.
