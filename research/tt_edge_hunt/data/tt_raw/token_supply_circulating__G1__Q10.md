### How this was built
- **Cohort**: five named entities — Ethereum, Solana, BNB Chain, and NEAR Protocol (each resolved to its own chain entity) plus Uniswap (its project entity); all five are non-archived.
- **Metric**: circulating supply in token units — the number of each entity's tokens available for trading on the open market — read from each entity's own project-level series and shown for each calendar day.
- **Window**: 2024-09-01 through 2024-11-30, one row per project per day (91 days × 5 entities = 455 rows).
- **No gaps**: every one of the 91 days has an observation for all five entities, so no day required a placeholder.
- The figures are unitless token counts (per the metric's format); they are point-in-time balances, not sums.
