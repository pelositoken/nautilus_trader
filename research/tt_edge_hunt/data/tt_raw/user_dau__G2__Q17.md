### How this was built
- Measure: daily active users — unique addresses making a revenue-generating transaction over a fixed 24-hour window — read per project per day, one row per named project per calendar day.
- Cohort: the five named projects, each resolved to its registry entry in the project registry (Ethena, Tron, Sui, Chainlink, Avalanche), all PUBLIC.
- Window: 2026-06-01 through 2026-08-31; every one of the 92 calendar days has a value for each of the five projects, so no day needed a gap placeholder.
- Values come from each project's own daily active-user rows; no aggregation was applied.
