### How this was built
- Cohort: Ethereum, Solana, BNB Chain and NEAR Protocol as chain projects, plus Uniswap as a project, each resolved by exact registry name; all five are public and live.
- Measure: circulating supply — the number of tokens available for trading — read as each day's value (a point-in-time count, not summed).
- Window: June 1 to August 31, 2023, daily, one row per calendar day. All 92 days carry a value for all five entities, so no day is blank.
