### How this was built
- Cohort: Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap, each resolved by exact name in the project registry.
- Measure: fees — gross value users pay to use the project; for the four chains this is each chain's own fee activity, not a rollup of the apps on it.
- Window: 2022-09-01 to 2022-11-30 (91 calendar days). Each of the five entities has a daily observation on all 91 days, so the table has no missing days and no gap placeholders were required.
- Values are USD.
