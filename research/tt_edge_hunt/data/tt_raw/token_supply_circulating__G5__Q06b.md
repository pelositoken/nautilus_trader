### How this was built
- Metric: circulating supply — the number of tokens currently available for trading on the open market, excluding locked, unvested, or treasury-held tokens; a point-in-time token count (not summed across days).
- Window: each calendar day from 2023-10-16 to 2023-11-30.
- Cohort: the five projects resolved by exact name — Polygon, PancakeSwap, OP Mainnet, Raydium, and Ether.fi.
- Every calendar day in the window is present as a row; a cell is blank where that project has no observation that day.
- Ether.fi has no circulating-supply observation on any day in this window, so its column is blank throughout.
- Polygon's first observed day in the window is 2023-10-26; its 2023-10-16 through 2023-10-25 cells are blank.
- Each value is read from the project's own circulating-supply series for that day.
