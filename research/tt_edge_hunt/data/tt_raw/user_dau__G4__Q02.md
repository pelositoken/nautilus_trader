### How this was built
- Cohort: the five projects named by the user, resolved in the project registry as Curve, Aptos, Jupiter, Celestia, and Render Network.
- Window: 2022-09-01 through 2022-11-30, one row per calendar day per project (91 days × 5 projects).
- Values are daily active users — unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window — read from each project's own metrics and summed over that day's rows.
- A "-" cell means no value was observed for that project on that day; it is not a zero.
- Metric definitions were omitted as requested.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
