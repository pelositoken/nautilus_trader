### How this was built
- Metric: circulating supply, a point-in-time token count from each project's own row; it is a snapshot per day and is not summed across days.
- Window: 2022-09-01 to 2022-11-30, one row per calendar day, from the project metrics surface.
- Curve and Render Network have a value on every day of the window; Aptos has values from 2022-10-19 onward. Jupiter and Celestia returned no values for any day in this window, shown as "-".
