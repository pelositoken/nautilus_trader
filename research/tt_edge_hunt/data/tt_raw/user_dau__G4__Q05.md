### How this was built
- The measure is active users (daily): unique addresses that make a revenue-generating transaction with the project in a fixed 24-hour window. It is a unique count, so each project's own daily reading is shown and the days are never summed; each value comes from the project's own row at project grain.
- Window: every calendar day from 2023-06-01 through 2023-08-31, one row per day, no gaps for the projects with data.
- Not reached: Celestia, Jupiter, and Render Network returned no daily active-user observations in this window. Jupiter and Render Network are not tracked for this metric, and no rows were returned for Celestia, so the table carries only Curve and Aptos.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.

_Token Terminal doesn't track Jupiter's active users (daily). Token Terminal doesn't track Render Network's active users (daily)._
