### How this was built
- The window is 2024-09-01 to 2024-11-30, one row per calendar day (91 days), each day returned whether or not the project has an observation; a day with no observation shows as empty.
- Metric: circulating supply — the number of tokens currently available for trading on the open market (a point-in-time token count, not a value and not summable across days). Values are token counts, unitless.
- Entities are the five named projects resolved in the registry: Aave, Injective, Filecoin, Ondo Finance, and Arbitrum One (listed in the table as the project names). Each is read from its own project-level rows; nothing is aggregated across days.
- The values come from the project-metric surface at project grain, one row per project per day, read as each day's own last observed value.
