### How this was built
- Cohort: the five named public projects — Ethena, Tron, Sui, Chainlink and Avalanche.
- Measure: daily active users — unique addresses making a revenue-generating transaction with the project, measured over a fixed 24-hour window — read day by day with no aggregation.

- A blank cell denotes a day with no observation for that project.
