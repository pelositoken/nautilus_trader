### How this was built
- Supply is the circulating supply metric — the number of tokens currently available for trading on the open market, excluding locked, unvested, or treasury-held tokens — read at its daily value (a point-in-time token count), not summed across periods.
- The five projects resolved by exact name to Ethereum, Solana, BNB Chain, NEAR Protocol and Uniswap; each is a PUBLIC, non-archived project.
- Window: 2026-03-01 to 2026-05-31, one row per calendar day per project; every one of the 92 days has a value for all five projects, so no day is left blank.
