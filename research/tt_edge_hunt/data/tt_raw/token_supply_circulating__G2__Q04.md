### How this was built
- The measure is each project's circulating supply (token count), read as one value per calendar day; a day's row is that day's latest reading.
- Window: 2023-03-01 through 2023-05-31, one row per calendar day, no aggregation.
- Ethena returned no rows for this window: circulating supply is not observed for it across these dates, so the table has no Ethena column.
- Sui's first day with a value is 2023-05-03; earlier days in the window have no Sui observation and are left as gaps.
- Dates with no observation for a project appear as an empty cell ("-").
- The daily-grain rows behind this table are available as a CSV export if you want them as a file.
