### How this was built
- Daily active users (unique addresses making a revenue-generating transaction over a fixed 24-hour window) for Curve, Aptos and Celestia, per calendar day, from 2024-09-01 through 2024-11-30, read at the project level.
- Not reached: Jupiter and Render Network daily active users — Token Terminal doesn't track active users (daily) for them.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
