### How this was built
- Measure: circulating supply — the number of tokens available for trading on the open market, excluding locked, unvested, and treasury-held tokens. A point-in-time token count, read as the day's value; not summed across days.
- Entities: Polygon, PancakeSwap, OP Mainnet, Raydium and Ether.fi, each resolved to its registry entry and read on the project surface.
- Window: 2025-12-01 to 2026-02-28 (90 calendar days), one row per date.
- Source: circulating supply reported per project per day; each day's value is that day's observation.
- Coverage: all 90 dates returned a value for all five projects, so no date required a "-" placeholder.
