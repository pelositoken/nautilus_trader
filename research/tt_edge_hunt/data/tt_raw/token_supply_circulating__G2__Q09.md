### How this was built
- Cohort: the five named projects, resolved in the project registry as Ethena, Tron, Sui, Chainlink and Avalanche.
- Window: 2024-06-01 to 2024-08-31, taken day by day with no aggregation; each day's value is that day's circulating-supply observation.
- Source: each project's own circulating-supply row, a point-in-time token count of tokens available for trading and excluding locked, unvested and project-treasury tokens.
- Coverage: all five projects have a value on all 92 days of the window (2024-06-01 through 2024-08-31), so no day is blank.
- Values are unitless token counts and are not comparable across projects; a blank day would be shown as "-", of which there are none here.
