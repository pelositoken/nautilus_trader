### How this was built
- The five projects were resolved by exact registry name: Curve, Aptos, Jupiter, Celestia and Render Network.
- The measure is active users (daily): unique addresses making a revenue-generating transaction with the project over a fixed 24-hour window, read per project per calendar day.
- Window: 2024-03-01 to 2024-05-31, one row per calendar day with no aggregation.
- Curve, Aptos and Celestia each returned a daily value on every day of the window.
- Not reached: daily active users for Jupiter and Render Network. Neither project returned an observation of this metric on any day of the window, so their columns are shown as - for every date; this is scoped to the metric, the two entities and the window above.
