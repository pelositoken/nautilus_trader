### How this was built
- Cohort: the five projects the question named — Ethena, Tron, Sui, Chainlink, Avalanche — resolved by exact project name; each is present on every date.
- Metric: circulating supply (token count) — the number of tokens available for trading on the open market — read as a daily snapshot per project.
- Window: a full calendar-day grid from December 1, 2022 through January 14, 2023 (45 days); no gaps were left, and a day without an observed value is shown blank.
- Values are unitless token counts.
- Ethena and Sui returned no value on any day in this window, so their columns are blank throughout; Tron, Chainlink and Avalanche each returned a value on every day. A blank only means no value was observed for that project and day — it is not a zero.
