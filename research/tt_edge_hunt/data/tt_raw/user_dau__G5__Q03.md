### How this was built
- Window: 2022-12-01 to 2023-02-28 (90 calendar days), returned as one row per entity per day with no aggregation.
- Cohort: Polygon, PancakeSwap, OP Mainnet, Raydium and Ether.fi, each read as its own project entity.
- Metric: daily active users — unique addresses making a revenue-generating transaction with the entity over a fixed 24-hour window — read per entity per day; because it is a unique count, each day’s value is that day’s own reading, never a sum across days.
- Coverage: Polygon, PancakeSwap, OP Mainnet and Raydium each have an observation on all 90 days. Ether.fi has one observation, on 2023-02-28, and shows “–” on every other day in the window.
- The full-grain daily rows (one row per entity per day) are available as a CSV export on request.

Caveat: this total sums precomputed unique-count buckets, so identities present in more than one time or entity bucket can be counted more than once. It is an upper bound, not a deduplicated unique count.
